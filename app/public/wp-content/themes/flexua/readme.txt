== Description ==

Flexua is a multi-purpose WordPress theme designed for IT services, startups, agencies, consulting firms, and other business websites. It provides pre-designed layouts and flexible content blocks for technology and service-based companies. The theme supports Elementor and is compatible with WooCommerce, WPML, Polylang, Yoast SEO, Contact Form 7, and Jetpack.


== Installation ==
	
1. In your admin panel, go to Appearance -> Themes and click the 'Add New' button.
2. Type in Flexua in the search form and press the 'Enter' key on your keyboard.
3. Click on the 'Activate' button to use your new theme right away.
